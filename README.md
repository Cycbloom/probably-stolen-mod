# 垃圾场拾荒地图 · 0.3.87

夜间外出，在城市地图选「垃圾场」并点「前往」，先选择一个作业区域，再进入拾荒。本次停留内连续拾荒沿用该区域；离开后重新选择。

| 区域 | 解锁声望 | 主要物资 |
|---|---:|---|
| 入口空地 | 0 | 常规材料、工具、日用品 |
| 生活废料带 | 0 | 食品、日用品、便宜药品 |
| 拆解堆 | 40 | 材料、工具、模组 |
| 医疗废弃点 | 40 | 绷带、药品、医疗器械 |
| 废武器堆 | 40 | 材料、近战、弹药、配件、枪支 |

地图地标旁的告示板展示当前设置和夜间事件生效后的主掉落概率。普通池和贵重品池可以含有同一种物品，分别列出；箱子与钥匙卡单独显示。概率会随设置、声望解锁及事件开始/结束更新。长名称单行省略，悬停可查看完整名称与概率；概率始终单独右对齐。周三等事件减半的是垃圾权重，再将全部掉落概率重新归一化，例如原本 25% 的垃圾概率变为约 14.3%。告示板显示当前事件倍率，期望价值也计入此修正；不含工具加成、额外奖品和第三方替换。

## 声望与奖励

每 100 点拾荒所得价值累计 1 点声望，零头保留；新增声望按游戏难度倍率结算。进度保存在当前存档的 modData 中。

| 声望 | 效果 |
|---:|---|
| 20 | 每天多一名拾荒客客人，收到便签「顺路来坐坐」 |
| 40 | 解锁三个高级区与离场搬运；收到便签「走的时候招呼一声」 |
| 60 | 提高隐藏储藏与小奖机会；大奖可触发次日报纸与市场事件 |
| 80 | 开放贵重品、补给箱和对应钥匙卡 |
| 100 | 收到拾荒者信物与便签「明天跟我们一起」，解锁夜间服务「与拾荒客同行」 |

帮手一次收费 50 信用点，优先搬运高价值物品；仓储放不下的物品仍会在离场时丢失。原离开、取消按钮照常工作。

三个节点在达标后的开张时向前台送便签，每档每个存档一次；前台放不下会下次重试。100 档的信物和便签一起发，放不下整组回滚。旧档已经领过信物的不会再送第二枚，会补齐尚未收到的三个节点说明。

## 夜间服务：与拾荒客同行

100 声望后在原版关店的夜间服务面板勾选「与拾荒客同行」，睡觉结算时由游戏统一收取 20 信用点。服务只预约下一天：次日当天多 2 次拾荒，拾荒时不会受轻伤或重伤；不会消除已有伤势，也不保护战斗伤害。与拾荒客开局的额外次数叠加，原版禁止拾荒的情况仍然不能拾荒。

结算后自动取消勾选，避免连续扣费。想再同行需头晚重新预约。效果日期写进当前存档，读档保留，过了对应日期自然失效。

## 拾荒客开局

新游戏可选「拾荒客」：每趟额外拾荒 2 次，夜间去垃圾场后次日客人不减；400 起始信用点，附简易储藏区、儿童背包、破败工具箱及三件工具、两份绷带。初始声望基准 20 点，随游戏难度倍率缩放。

## 设置

在 Mod 设置中调节垃圾倍率、区域专精度、贵重品/奖品概率和地面窗口。默认垃圾倍率 50%、专精度「较多」75%、贵重品概率 3%（80 声望后生效），地面 19×21。拖动滑条时实时预览，松手或应用时写入配置。

新增「启用大奖概率拥塞窗口」开关，默认开启：开启时按原来的慢启动、线性增长、中奖减半动态调整；关闭时每次直接用「爆大奖概率上限」作为中奖率。两种模式在声望不足 60 时都仍受 0.1% 上限限制，每趟最多一次大奖。关闭时暂停旧窗口的增长和减半，再开启后继续原进度；告示板同步显示当前模式的概率。

调试声望默认关闭。主菜单手动设置的调试点数会排队到下一次读档或新档；当前存档保存失败后的重试绑定原存档，不会套到另一档。

## 安装与兼容

将发布包中的 DLL、manifest.xml 和 Paper 文件夹放入游戏的 Mods/DumpingGroundMap/，关闭游戏后更新，在 Mod 管理中启用。

模块复用原有受伤、空手、拾荒次数、工具和背包流程。主掉落先发送 OnLootRolled，再按事件最终返回的物品 ID 生成物品。第三方替换 ID 时采用新 ID，保留原 ID 时保留本模组的真伪/状态变体。奖励仍只走奖励自身的生成规则。

可选联动：Reputation Pop、背包挂钩、势力声望面板重制。涉及同一拾荒入口的其他 Mod 仍需组合试玩。模组 ID、开局 ID、既有存档键和配置键沿用旧版。
