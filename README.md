# 垃圾场拓展 · 1.0.3

夜间外出，在城市地图选「垃圾场」并点「前往」，先选择一个作业区域，再进入拾荒。本次停留内连续拾荒沿用该区域；离开后重新选择。

选区页是一座完整的八地点垃圾场：外围废料山、围栏与货柜围出边界，内部以窄通道串起作业区。底图和八处透明地标分层绘制；鼠标悬停时地标平滑放大并显示物资倾向，锁定地点会压暗并显示门槛。点击地标或附近有效地面放下 X，再点显示目的地名称的按钮确认；外围与远离地点的废料不接受选点。本次停留沿用所选区域，没有交界处混合掉落。

名称和状态由实时 UI 显示，物品概率集中到地图下方的「查看物品概率」按钮。进入后按区域切换背景；离场、读档或禁用时恢复原版背景。素材按游戏原生路径打包到 `Textures/Paper/`；生成提示词见 [美术提示词](docs/ART-PROMPTS.md)。

| 区域 | 解锁声望 | 主要物资 |
|---|---:|---|
| 入口空地 | 0 | 常规材料、工具、日用品 |
| 生活废料带 | 0 | 食品、日用品、便宜药品 |
| 废泵站 | 20 | 储水容器、净水检测用品 |
| 拆解堆 | 20 | 原材料为主，少量拆卸工具 |
| 医疗废弃点 | 40 | 绷带、药品、医疗器械 |
| 废武器堆 | 60 | 材料、近战、弹药、配件、枪支 |
| 电子垃圾坡 | 60 | 电子件、线缆、工具、模组 |
| 报废车场 | 40 | 材料、工具、可拆零件 |

「查看物品概率」顶部显示当前地点的主掉落收益拆分：基础期望 + 贵重品净增益 + 箱卡净增益 = 主掉落合计（信用点/件）；另列大奖、小奖按当前概率计算的期望贡献（信用点/次搜索）。悬停可查看中奖平均价值、概率和估算范围，数值随当前声望、设置、事件与本趟大奖状态更新。窗口同时展示当前生效的主掉落概率。普通池和贵重品池可以含有同一种物品，分别列出；箱子与钥匙卡单独显示。概率会随设置、声望解锁及事件开始/结束更新。长名称单行省略，悬停可查看完整名称与概率；概率始终单独右对齐。周三等事件减半的是垃圾权重，再将全部掉落概率重新归一化，例如原本 25% 的垃圾概率变为约 14.3%。告示板显示当前事件倍率，期望价值也计入此修正；不含工具加成、额外奖品和第三方替换。

废泵站普通拾荒中的可装水瓶、桶自带 10%–100% 容量的水，按截断正态分布抽取，55% 容量附近最常见、两端少见；普通瓶和大瓶更常见，小瓶与桶更少见（5%/45%/45%/5%）。水质以幽灵水为中心：纯净水/优质水/基础水/幽灵水/锈水/沟流水的概率为 1/6/24/39/24/6%，使用游戏原生污染物和净水机制。泵站主题表不再生成空啤酒瓶、酒瓶或固定水质饮水包。小奖、大奖和中奖后的当日额外收获只给净水、检测耗材与设备；普通拾荒的 80 档贵重品规则保留。

泵站的水质检测盒和净水药片瓶只会出现满装或半装：试纸为 10 张或 5 张，药片为 9 颗或 5 颗。包装内存放真实耗材，普通掉落、大小奖和额外奖励都不会单独给散装试纸、单颗药片或空包装；告示板与小奖件数按内容价值计算。

海德拉科技微型净水器的新拾荒产物有剩余使用量三档：1/3、1/2、全满，三档等概率。原生最大使用量为 300，分别剩余 100、150、300；普通拾荒和奖励共用此规则，使用消耗与售价按原生耐久机制处理。告示板估值已计入三档剩余使用量的平均价值。

## 基础收益与地点差异（0.5.0）

以 12.24 为设计基准，所有已开放地点在声望 0/20/40/60 时的主掉落基础期望分别为 12.24/13.464/14.688/15.912；按初始值线性累计 +0/+10/+20/+30%，达到 60 后基础目标不再增长。旧地点会同步升级，物品售价保持原生机制，通过类别内部概率调整收益，大类占比保留。大小奖及中奖后的额外收获独立结算；80 档贵重品、100 档补给箱与钥匙卡在基础分布外按既有配置独立加入。

设置页按声望 0/20/40/60/80/100 展示各档已开放区域的平均主掉落期望，分列基础、贵重增益、箱卡增益并标记当前档。数值随当前设置刷新，以无临时事件的常态比较成长；80 档加入贵重品，100 档再加入箱卡；同行服务不改变单件期望。当天地点事件的实际收益仍在选区告示牌查看。

目标校准条件为垃圾倍率 100%、无夜间垃圾事件、未加入80档稀有份额，含垃圾的一次主掉落；不代表点击一次搜索所得整批物品的总价值。八区常态垃圾率统一50%，垃圾倍率50%时实际垃圾率25%，自定义设置和事件会改变当前收益。默认垃圾倍率改为100%，范围0–150%；已有手动配置保留，点“默认”可恢复新默认值。

拆解堆的非垃圾部分以原材料为主（75%原料、20%工具、5%电子残件）；电子垃圾坡为50%电子件、35%模组、15%精密工具；报废车场为55%维修工具、35%机械材料、10%可拆零件。对应大小奖同步偏向原料垛、电子库存、工具箱，奖品概率和计价不纳入上述基础目标。

泵站在全部区域专精下：垃圾50%、储水容器31%、净水检测用品10%、日用品9%。由于真实瓶内水也有价值，采用该构成校准统一收益；保持容器多于净水用品，并固定瓶型的5/45/45/5分布。专精降低时仍会混入通用物品，类别内部进行收益校准。

详细口径与实算概率见 [0.5.4 数值说明](docs/BALANCE-0.5.4.md) 和 [逐物品概率表](docs/BALANCE-0.5.4.csv)。

贵重品与箱卡会替代部分普通掉落，因此显示净增益；基础列保留不加入稀有份额时的期望，三项相加与实际主掉落总期望一致。大奖小奖按完整中奖批次估价，小奖计入大奖优先和1–12件限制；工具、额外主掉落、中奖后的额外收获与市场效果另算。

箱卡在100声望开启，八区各有不同组合，入口也已补齐。箱子与卡独立掉落且类型配套，概率设置控制各自总概率。入口另有通用日常补给小奖，八区小奖各有分工；具体分配见 [区域箱卡与小奖表](docs/REGIONAL-REWARDS-0.5.3.md)。概率窗口列出每种箱卡的实际概率，悬停“小奖”可查看本区整箱内容。

## 声望与奖励

每 100 点拾荒所得价值累计 1 点声望，零头保留；新增声望按游戏难度倍率结算。进度保存在当前存档的 modData 中。

| 声望 | 效果 |
|---:|---|
| 20 | 开放拆解堆、泵站，所有已开放区基础收益目标 +10%；每日多一名拾荒客，收到便签 |
| 40 | 开放报废车场、医疗点，所有已开放区基础收益目标 +20%；解锁离场搬运，收到便签 |
| 60 | 开放电子垃圾坡、废武器堆，所有区域基础收益目标 +30%；隐藏储藏与小奖机会独立提高 |
| 80 | 开放贵重品 |
| 100 | 开放补给箱及对应钥匙卡；收到拾荒者信物与便签「明天跟我们一起」，解锁夜间服务「与拾荒客同行」 |

帮手一次收费 50 信用点，优先搬运高价值物品；仓储放不下的物品仍会在离场时丢失。原离开、取消按钮照常工作。

三个节点在达标后的开张时向前台送便签，每档每个存档一次；前台放不下会下次重试。100 档的信物和便签一起发，放不下整组回滚。旧档已经领过信物的不会再送第二枚，会补齐尚未收到的三个节点说明。

## 夜间服务：与拾荒客同行

100 声望后在原版关店的夜间服务面板勾选「与拾荒客同行」，睡觉结算时由游戏统一收取 20 信用点。服务只预约下一天：次日当天多 2 次拾荒，拾荒时不会受轻伤或重伤；不会消除已有伤势，也不保护战斗伤害。与拾荒客开局的额外次数叠加，原版禁止拾荒的情况仍然不能拾荒。

结算后自动取消勾选，避免连续扣费。想再同行需头晚重新预约。效果日期写进当前存档，读档保留，过了对应日期自然失效。

## 拾荒客开局

新游戏可选「拾荒客」：每趟额外拾荒 2 次，夜间去垃圾场后次日客人不减；400 起始信用点，附标准储藏区（可放容器和机器）、儿童背包、破败工具箱及三件工具、两份绷带。初始声望基准 20 点，随游戏难度倍率缩放。标准储藏区仅在新开局发放，更新不会替换旧存档中的家当。

免扣客流依据当前存档的垃圾场访问日期，早晨重新读档后仍生效；对应的夜间报告不会再误称因拾荒错过顾客。此效果与 20 声望每天额外一名拾荒客分开结算，两者可以叠加。原版在开门时重新生成当天顾客，因此请在同样条件下开门比较读档前后的客流。

## 区域日事件

八个地点各有每周事件，当天最多两区发生、每个已开放地点每周一次。地图标出今日事件，悬停/选中可查看效果和期望收益，概率窗口单列事件增益。日期随存档保存，原版全场事件继续生效。具体效果与周中解锁规则见[区域事件说明](docs/REGIONAL-EVENTS-0.6.0.md)。

## 设置

设置页按0/20/40/60/80/100声望档显示已开放区域的常态平均收益，拆分为“基础 + 贵重品净增益 + 箱卡净增益 ≈ 合计”；当天事件在地点告示牌单独计入。掉落预设只保留“默认”和“加强”两档，具体参数见 [设置说明](docs/SETTINGS-0.5.5.md)。

在 Mod 设置中调节垃圾倍率、区域专精度、贵重品/奖品概率和地面窗口。垃圾倍率范围0–150%、默认100%，专精度「较多」75%、贵重品概率3%（80 声望后生效），地面 19×21。拖动滑条时实时预览，松手或应用时写入配置。

大小奖都有独立拥塞窗口，默认开启。大奖按游戏自然日更新：连续5个未中日到上限，中奖后次日减半，当天概率固定。小奖按每次搜索更新：未中先翻倍、后每次增加0.1个百分点，中奖减半，设置值为概率上限。关闭对应窗口时使用固定上限并暂停进度。声望限制、大奖每趟一次和大奖优先保留，告示牌按当前实际概率计算期望，详见[大小奖窗口说明](docs/REWARD-WINDOWS-0.6.1.md)。

调试声望默认关闭。主菜单手动设置的调试点数会排队到下一次读档或新档；当前存档保存失败后的重试绑定原存档，不会套到另一档。

## 安装与兼容

将发布包中的 DLL、manifest.xml 和 Textures 文件夹放入游戏的 Mods/DumpingGroundMap/，贴图应位于 Mods/DumpingGroundMap/Textures/Paper/。关闭游戏后更新，在 Mod 管理中启用。

模块复用原有受伤、空手、拾荒次数、工具和背包流程。主掉落先发送 OnLootRolled，再按事件最终返回的物品 ID 生成物品。第三方替换 ID 时采用新 ID，保留原 ID 时保留本模组的真伪/状态变体。奖励仍只走奖励自身的生成规则。

可选联动：[拾荒拓展：背包、技能与焚化炉](https://steamcommunity.com/sharedfiles/filedetails/?id=3832768562)、更好的拾荒、Reputation Pop、[店铺便捷升级：背包挂钩/桌面工具箱/NPC鉴别](https://steamcommunity.com/sharedfiles/filedetails/?id=3832013611)、势力声望面板重制。没有强制前置。涉及同一拾荒入口的其他 Mod 仍需组合试玩。模组 ID、开局 ID、既有存档键和配置键沿用旧版。

工坊发布资料、干净打包与上传脚本见 [发布说明](workshop/README.md)。正式署名为 Cycbloom，保留 `local.dumping_ground_map` 作为持久ID。
