# 设置更新 · 0.5.5

垃圾倍率范围0–150%，默认100%。无事件时，倍率0/50/100/150分别对应0/25/50/75%的垃圾概率。夜间事件仍按垃圾权重改变后重新归一化。

## 两档掉落预设

| 参数 | 默认 | 加强 |
|---|---:|---:|
| 垃圾倍率 | 100% | 50% |
| 区域专精 | 75% | 100% |
| 贵重品概率 | 3% | 5% |
| 补给箱总概率 | 1% | 1% |
| 钥匙卡总概率 | 1% | 1% |
| 小奖概率上限 | 3% | 5% |
| 小奖整箱目标价值 | 200 | 250 |
| 大奖概率上限 | 1% | 2% |
| 大奖动态窗口 | 开启 | 开启 |
| 小奖动态窗口 | 开启 | 开启 |

声望门槛继续生效：低于60时小奖当前概率按1/10、大奖上限至多0.1%；贵重品在80声望开启，箱卡在100声望开启。0.6.1起，大奖窗口按天更新、连续5个未中日到顶，小奖窗口按搜索更新；详见[大小奖窗口](REWARD-WINDOWS-0.6.1.md)。预设只影响掉落参数，地面尺寸/对齐、调试和联动开关不在本预设中。已有配置保留，点击“默认”可恢复新默认值。

## 实时收益显示

自 0.6.7 起，按声望 0/20/40/60/80/100 六档显示：基础期望 + 贵重品净增益 + 箱卡净增益 ≈ 主掉落合计，单位信用点/件。各档仅平均该声望下已开放区域，数量为 2/4/6/8/8/8，当前档用强调色标记。基础为相同设置下未加入稀有份额时的主掉落期望；增益扣除被替代普通物品的价值，避免重复计算。

声望比较固定为无全场/区域事件的常态，不受当前日期或实际声望影响，也不改写玩家声望和存档。80 档加入贵重品，100 档加入箱卡；同行服务不增加单件期望。大小奖、工具、额外主掉落和后续额外收获另算；外来物品缺少估值时按 0 计。主掉落合计不等同一次搜索产生的整批物品价值。当天区域事件的实际期望仍在告示牌查看，设置行悬停可读完整计算口径。

拖动滑条、切换专精和应用预设实时刷新。预设也同步专精、大奖上限滑条与窗口开关，避免随后点击应用时被旧控件值覆盖。
