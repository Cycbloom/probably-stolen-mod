# 泵站容器增量与收益校准 · 0.5.4

垃圾倍率100%、全部区域专精、无夜间事件、未计80档稀有份额时：

| 类别 | 旧版 | 新版 |
|---|---:|---:|
| 垃圾 | 50% | 50% |
| 储水容器 | 22% | 31% |
| 净水与检测用品 | 10% | 10% |
| 日用品 | 18% | 9% |

日用品减半，全部9个百分点移给储水容器。专精较低时仍混入原版通用物品，实际比例随当前设置计算。

为维持同声望下各地点基础收益接近，储水类内部改为小瓶/普通瓶/大瓶/桶=5/45/45/5。普通瓶与大瓶合计占90%，两端更少见。在上述基准下，普通瓶和大瓶各占全部掉落13.95%，小瓶和桶各1.55%。

泵站在20/40/60声望的基础目标仍为13.464/14.688/15.912。只调整瓶型和类别内部物品概率，不修改原生售价；水量仍以55%容量为中心，水质仍以幽灵水为峰值。净水设备、包装内容、箱卡和奖品概率保留。

原15/35/35/15瓶型搭配31%容器时，最低基础期望约15.3146，高于20档目标；新5/45/45/5构成的最低期望约13.4499，使各已开放声望档均能达到统一目标。

[实算逐物品概率表](BALANCE-0.5.4.csv)由编译后的代码导出，包含40组已开放区域配置（75%及100%专精）。主掉落口径包含垃圾，大小奖及80稀有份额另计。
