# 大小奖窗口 · 0.6.1

## 大奖：每个游戏自然日更新一次

当天的抽奖概率保持固定，每次搜索都使用这个概率，仍为每趟最多中一次。搜索次数不会推进日窗口。窗口开启时，没有外出拾荒的日子也算一个未中奖日。

从本轮起点开始，把起点到上限之间的差额分为5份，每个未中大奖的日子增加一份。默认起点0.05%、上限1%时，逐日概率为：0.05% → 0.24% → 0.43% → 0.62% → 0.81% → 1.00%。

中奖当天概率不变；下一天把窗口减半（最低0.05%），并从减半后的值重新开始5个未中日的增长。若一天内多趟中奖，只在次日减半一次。声望不足60时实际上限仍不超过0.1%；调整上限/跨越声望门槛时，以当前概率重建增长周期。

固定模式直接使用实际生效上限，暂停窗口。重新开启不补算关闭期间的日期，固定模式中奖也不会改变保存的动态窗口。读档按存档日期与最后处理日期同步，不会因反复打开告示牌或同日多次搜索重复更新。

旧存档保留已有stash_chance作为新日周期起点，不回算升级前的历史未中日。新增日期、周期起点、未中天数、生效上限和动态中奖日期等键都在当前存档的模组数据内；原有新闻与当天同区额外奖励规则保留。

## 小奖：每次有效搜索更新一次

设置中的“小奖概率上限”默认3%，加强档5%，范围0–10%。新增“启用小奖概率拥塞窗口（每次搜索）”，默认开启，两档预设均开启。

- 起点为上限的1/10，最多0.3%。默认上限3%时从0.3%开始。
- 未中且尚未到上限一半时先翻倍：0.3% → 0.6% → 1.2% → 2.4%。
- 随后每次未中增加0.1个百分点：2.5%、2.6%……直到3%。
- 中奖后当前窗口减半，此后按加法恢复；不低于起点。
- 声望不足60时，当前窗口概率再乘1/10，例如0.3%窗口对应实际抽奖0.03%，最高3%窗口对应0.3%。
- 上限0时不抽奖也不增长。关闭窗口时按固定上限抽奖，保存的窗口概率和阶段暂停。

每次有效搜索只更新一次。大奖优先；若该次搜索出了大奖，小奖不发放，仍计一次小奖未中并增长窗口。大小奖窗口独立，各区域共用，换区、跨天不清零，小奖中奖不影响大奖日窗口。

## 告示牌

大奖期望 = 整批大奖平均价值 × 当前实际大奖概率。

小奖期望 = 整箱小奖平均价值 × 当前小奖窗口实际概率 ×（1 − 当前大奖概率）。

小奖行直接显示扣除大奖占用后的最终概率；悬停同时列出扣除前的当前抽奖概率和声望限制后的概率上限。大奖行说明每日更新与每趟一次限制；本趟已中过大奖时概率为0，小奖不再被大奖占用。

大小奖不并入基础、贵重品、箱卡和区域事件的主掉落收益合计。奖励池、整箱目标价值、区域事件均保持原有规则。
