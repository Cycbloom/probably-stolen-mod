# 验证与试玩

自动检查使用编译后的实际 Mod DLL。规则测试通过 .NET Framework 控制台进程运行，不需要启动 Unity；修改图形界面后仍需目视试玩。

```powershell
./build.ps1 -Check
./tools/verify.ps1 -Scan
```

## 自动覆盖

- 5 区 × 3 垃圾档 × 5 专精值 × 3 贵重品档 × 2 解锁状态，共 450 组概率配置；非负、归一化、档位门控、箱卡保留份额及边界抽取。
- 每区 10,000 个等距样本，抽取结果与目标概率相符；零概率槽位不参与。
- 主题物品及所有最终槽位的估值覆盖；贵重品定义的区域权重有效。
- 告示板分组覆盖最终表，普通与贵重池里的同名模组提取器分别展示；箱子/钥匙卡单独计入。
- 五个计算输入和 80 档状态变更均使缓存更新；从高声望读回低声望时关闭贵重品。
- 掉落事件保持变体、替换 ID、取消 ID 三种结果。
- 60 点小奖倍率边界、100 档未开放文案；嵌套恢复与重复恢复；搜索异常 Finalizer 保留原异常并清状态。
- 延迟保存身份匹配，拒绝不同对象、runID 或槽位。
- 游戏原生 ModScanner 的拒绝项和能力检查。

0.3.82 的一次性数据对照以 2b86fd6（0.3.81）为基准：原版参考表、五区主题表、26 项贵重品的五区权重、153 条估值记录完全一致。此对照验证数据搬迁，不代表其它 Mod 替换后的实战收益。

## 游戏内回归清单

1. 普通旧档读档 → 进垃圾场选区 → 连续拾荒 → 取消/离场/重新进入；确认区域、次数和原有受伤规则。
2. 在 39/40、59/60、79/80、99/100 附近查看地图与声望说明；切到另一个声望较低的档再查看。
3. 非满专精查看生活废料带、医疗废弃点、废武器堆；普通模组提取器应出现。80 点后确认箱子/钥匙卡概率行和贵重品组。
4. 拖动概率设置、换专精、点预设，告示板与数值应即时刷新；开关面板后仍正常。
5. 新开拾荒客：400 信用点、破败家当、难度缩放的初始声望；两条被动仅对该开局生效。
6. 地面窗口九宫格对齐、不同尺寸；堆满时提示；离场帮手的付费、钱不足、仓储不足、取消和原版离开。
7. 与已有工具/拾荒增强、Reputation Pop、背包挂钩、声望面板重制组合测试。若订阅 OnLootRolled 的 Mod 替换 ID，实际物品应采用新 ID。
8. 游戏内改调试声望后立即退菜单、切档、禁用再启用；确认没有跨档保存或跨档注入值。

本轮执行了自动验证与数据对照，以上图形界面和组合运行场景留待试玩。
