# 区域日事件 · 0.6.0

八个地点各有一个事件。地图顶部列出今日事件，发生地点下方显示金色“今日”标签。悬停或选中查看效果、今日结束提示和主掉落期望；完整说明可通过地点详情、概率窗口中的事件提示查看。

## 事件与参数

| 区域 | 事件 | 普通垃圾权重 | 特产倾向与额外效果 |
|---|---|---:|---|
| 入口空地 | 分拣后的废料 | −25% | 轻伤、重伤概率相对降低20% |
| 生活废料带 | 商铺集中清仓 | −25% | 食品、日用品权重最多+50% |
| 拆解堆 | 工坊清运 | −40% | 原材料权重最多+50% |
| 电子垃圾坡 | 设备换代 | −25% | 电子件与可用模组权重最多+50%，不提高损坏/腐坏模组权重 |
| 报废车场 | 新车入场 | −20% | 工具、可拆机械零件权重最多+50% |
| 医疗废弃点 | 药房清库 | −40% | 医疗耗材、药品权重最多+50% |
| 废武器堆 | 军械清退 | −25% | 弹药、武器配件权重最多+50% |
| 废泵站 | 储水罐排空 | −15% | 带水容器权重最多+50%；普通容器水量分布中心55%→65% |

所有百分数均为相对权重/风险变化，不是加减概率百分点。拆解堆和医疗区偏向实用、低价物品，因此使用更强的垃圾减免；泵站同时提高水量，垃圾减免较小。

特产倾向只在普通非垃圾池内重分配，并保留各类内的相对分布。普通垃圾权重降低后，在普通池内部归一化。默认配置、无原版全场事件、0–60声望对应已开放区域的主掉落期望增幅约10%–20%。极端设置下（如垃圾倍率为0）若完整特产倾向反而降低货币期望，会减少倾斜幅度，确保事件收益不下降；不会提高物品售价。实际期望与概率见[导出数据](EVENTS-0.6.0.csv)。

泵站水量仍为10%–100%截断钟形分布、标准差18个百分点。水质仍以幽灵水最多，小瓶/标准瓶/大瓶/桶的专精瓶型比例仍为5/45/45/5；事件仅改变普通主掉落新生成容器的水量。贵重品、奖品与已有物品不套用此水量变化。

## 周计划与存档

- 与原版日历一致：dayCounter % 7，周日为0。周初对已开放区域安排本周日期，一区一次，同日最多两区，优先分散到空日期。
- 日期与稳定种子存入当前存档的模组数据：regional_event_week、regional_event_days、regional_event_seed。新档、读档、切档、热启停均重新绑定当前存档。
- 中途解锁区域从次日起加入本周尚有容量的日期，不移动已有事件。首次安装到周中旧档时只安排剩余日期；本周剩余容量不足的区域从下周正常参与，不补发过去事件。
- 普通拾荒结算声望后立即记录解锁，避免当天最后一次拾荒解锁后漏掉次日安排。存档使用既有DeferredSave延后一帧保存，避免在读档初始化中途快照。
- 事件只持续当天；读档不会重抽日期。安排使用独立确定性算法，不消耗Unity的战利品随机数。

## 计算与展示

先完成声望基础校准、稀有份额分配及原版全场事件，再在普通池应用区域事件。原版“新到的垃圾”等仍照常覆盖整个垃圾场。区域事件不改变每个贵重品、补给箱和钥匙卡槽位的概率，不改变大奖/小奖概率、奖池、动态窗口或声望门槛。

收益展示为：同日无区域事件的基础期望 + 贵重品净增益 + 箱卡净增益 + 当前区域事件净增益 = 当前主掉落期望。事件项是同设置、同声望、同全场事件条件下两张表的差值。大奖、小奖保持单独按每次搜索显示；工具、额外主掉落、市场与议价效果不合并。

入口事件只在实际选定并进入入口空地时乘以0.8，原生轻重伤显示和实际掷骰共用两个概率方法。已有免伤仍为0；原版新垃圾风险×1.25与入口事件×0.8可同时生效。
