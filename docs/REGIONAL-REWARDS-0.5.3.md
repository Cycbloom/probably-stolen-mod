# 区域箱卡和小奖分配 · 0.5.3

使用原生工程、服务、医疗、安保四类上锁满箱，各类型配套原生钥匙卡，保留真实开锁与箱内内容。八区以类型组合和权重形成差异，不创建只换名字的同内容箱子。

| 区域 | 箱型与卡型的内部权重 | 小奖方向 |
|---|---|---|
| 入口空地 | 服务50%、工程30%、医疗20% | 咖啡因片、牙膏、普通绷带、打印耗材、螺丝刀 |
| 生活废料带 | 服务100% | 肉类食品、能量饮料、冰淇淋、零食、纸品 |
| 拆解堆 | 工程100% | 废金属、打印耗材、螺丝、金属锭、布料 |
| 废泵站 | 服务80%、医疗20% | 滤芯、滤水器、带内容的检测盒和净水药片瓶 |
| 报废车场 | 工程60%、服务40% | 剪线钳、焊接工具、螺丝刀、美工刀、增压器、撬棍 |
| 医疗废弃点 | 医疗100% | 止血绷带、药片、消毒酒精、血袋、医疗用品 |
| 电子垃圾坡 | 工程90%、安保10% | 电子元件、线缆、损坏/受损模组、空白模组 |
| 废武器堆 | 安保100% | 子弹、弹匣、美工刀、厨房刀、打印枪 |

箱卡均在80声望开启。箱子与卡独立掉落、共享本区的类型权重；服务箱配ser_keycard、工程箱配eng_keycard、医疗箱配med_keycard、安保箱配sec_keycard。

设置中的补给箱概率是所有箱型合计，钥匙卡概率是所有卡型合计。例如入口在默认各0.5%时，服务箱/卡各0.25%、工程箱/卡各0.15%、医疗箱/卡各0.10%，不按每种类型另加0.5%。夜间垃圾权重事件仍会按原规则归一化最终概率。

小奖按区域随机选一种，整批同类物品，件数继续按目标价值、单价和1–12件限制计算。入口也沿用小奖现有低声望1/10、高声望全值的规则。奖品与箱卡的收益继续显示在独立期望项中，不改0–60声望基础收益目标。

原生卡片目录单价：服务40、工程75、医疗75、安保100信用点。箱子沿用既有内容估价，实际内容受游戏原生随机填充影响。概率窗口列出各类型概率，小奖内容可悬停查看。
